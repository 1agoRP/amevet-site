# AMEVET — Clínica Veterinária e Estética Animal

Site institucional da AMEVET, na Vila Medeiros, Zona Norte de São Paulo.

- **Código do site:** [`site/`](site/) — React 19 · TypeScript · Tailwind CSS · Vite
- **Documentação completa:** [`site/README.md`](site/README.md)
- **Arte original da marca:** `Logo.png` (fonte para `site/scripts/gerar-marca.mjs`)

```bash
cd site
npm install
npm run dev
```

> O `site/README.md` lista os três pontos que ainda precisam de confirmação da
> clínica antes de o site ir ao ar: horário de funcionamento, número do WhatsApp
> e substituição das fotos de banco pelas fotos reais.
